# Archivo de informes anteriores

Se trasladó aquí todo el contenido anterior de `docs/`, incluyendo siete QMD, sus HTML, figuras, bibliotecas de presentación y la propuesta metodológica. El traslado conserva los archivos íntegros: `archive_manifest.csv` registra las rutas originales y nuevas, el tamaño y SHA-256 de los 207 archivos archivados.

Los documentos vigentes son `../docs/index.qmd`, `../docs/rem.qmd` y `../docs/grd.qmd`. Sus versiones HTML están en la misma carpeta `docs/`.

También se conserva una copia histórica de `build_consolidation_report.py`. No es el generador vigente: la publicación local de los tres informes se realiza con `python scripts/render_reports.py` desde la raíz del repositorio.

Los informes históricos contienen las limitaciones metodológicas señaladas durante la auditoría. No se regeneran ni se incluyen al renderizar el proyecto de `docs/`. Las rutas de datos originales en su código se conservaron tal como estaban; este archivo tiene función de trazabilidad, no de ejecución activa.
